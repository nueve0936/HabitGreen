# Capturas de los mockups

Capturas de las pantallas de Figma, como referencia de diseño mientras el MCP de Figma no esté disponible.

Cómo exportarlas sin el MCP: en Figma, selecciona el frame, abre *Export* en el panel derecho, elige PNG (1x o 2x) y guarda el archivo aquí.

Nombres sugeridos (en kebab-case, con el nombre de la pantalla):

- `jardin.png`
- `tienda.png`
- `tienda-compra.png`
- `tienda-compra-2.png`
