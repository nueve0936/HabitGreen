# Plantas (SDD 9.8)

Una planta por categoría, con 3 fases. Copia aquí los PNG con estos nombres exactos:

| Categoría | Fase 1 | Fase 2 | Fase 3 |
| --- | --- | --- | --- |
| Salud física | `salud_fisica/fase1.png` | `salud_fisica/fase2.png` | `salud_fisica/fase3.png` |
| Trabajo / Estudio | `trabajo/fase1.png` | `trabajo/fase2.png` | `trabajo/fase3.png` |
| Salud mental | `salud_mental/fase1.png` | `salud_mental/fase2.png` | `salud_mental/fase3.png` |
| Finanzas | `finanzas/fase1.png` | `finanzas/fase2.png` | `finanzas/fase3.png` |
| Social | `social/fase1.png` | `social/fase2.png` | `social/fase3.png` |

Formato final:

- PNG con fondo transparente.
- Lienzo cuadrado e igual para todas (por ejemplo, 1024 × 1024), con la maceta en el mismo lugar en las 3 fases, para que el cambio de fase no "salte".
- Contorno oscuro (`#2C1E18`), para que se distingan sobre el panel verde claro.

Las ilustraciones provisionales pueden tener otro tamaño o fondo: la app las escala y se reemplazan después con el mismo nombre, sin tocar el código. Las actuales son provisionales: 3 fases distintas (brote, planta y planta con flores) en 512 × 512, iguales para todas las áreas.
